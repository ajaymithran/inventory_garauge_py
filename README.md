# inventory.py Project

![Python Banner](banner.svg)

## What the program does

This script lets the user:
- buy items from an inventory
- restock items
- continue the program by choosing yes or no

## Items available

- sword
- shield
- potion

## How to run

```bash
python inventory.py
```

## Example

When you run the program, you can type:
- buy
- restock

and choose an item from the list.
